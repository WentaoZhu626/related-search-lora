## 解读提示

- OOD 相对 ID 的下降幅度要结合置信区间看：区间明显重叠时，差异不显著。
- “标准答案词在训练集中出现过的比例”越低，说明该测试集越依赖模型对新词汇的泛化，精确匹配 F1 天然会更低，软匹配更有参考价值。
- 结论只适用于“同一 Pinterest 风格分布内、训练时没见过的语义主题”，不代表真实 Nalook 线上 query 的表现。
